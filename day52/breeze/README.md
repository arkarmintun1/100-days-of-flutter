# Day 52: A Modern Weather UI - Glassmorphism & Dynamic Backgrounds

The **Breeze** app at the end of Day 52 of [100 Days of Flutter](../../README.md).

Article: https://arkar.dev/day-52-weather-ui-glassmorphism/

```bash
fvm flutter pub get
fvm dart run build_runner build
cp .env.example .env   # then add your API key
fvm flutter run
```

Location permissions are already added to `AndroidManifest.xml` and `Info.plist`. For the iOS permission setup of `geolocator`, see the Day 50 article.
